Como funciona a API

O navegador usa fetch() para enviar requisicoes HTTP para o servidor Express. O servidor executa a query no MySQL e devolve JSON.

  • GET /api/humans — Lista todos os adotantes
  • GET /api/humans/:id — Busca por ID
  • POST /api/humans — Cria novo registro
  • PUT /api/humans/:id — Atualiza registro
  • DELETE /api/humans/:id — Remove registro

  • CRUD completo via fetch()
  • Feedback visual para o usuario
  • Tabela com edicao e remocao

Fluxo de dados

1. Usuario preenche o formulario
2. JS chama fetch()
3. Express recebe a requisicao
4. Controller chama o Model
5. Model executa o SQL
6. Resposta JSON retorna ao navegador
7. Pagina atualiza a tabela
